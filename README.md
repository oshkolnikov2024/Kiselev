# Kiselev — лендинг строителя

Одностраничный сайт для специалиста по малоэтажному строительству и ландшафтному дизайну в Уральском регионе.

Папка проекта: `C:\D\Zerocoder\Вайб кодинг\Cursor\Kiselev`

## Структура

- `index.html` — разметка
- `styles.css` — стили
- `script.js` — меню, анимации, форма
- `images/hero.png` — ваше фото (главный экран)
- `images/about.png` — ваше фото (блок «О мастере»)

## Как заменить фотографии

1. Положите свои снимки в папку `images/`
2. В `index.html` замените пути:
   - `images/hero.png` — фото на первом экране
   - `images/about.png` — фото в блоке «О мастере»
3. В секции «Портфолио» замените ссылки Unsplash на локальные файлы, например:
   ```html
   <img src="images/portfolio-1.jpg" alt="Описание">
   ```

## Что ещё настроить

- Название бренда «УралДом» в шапке и подвале
- Телефон и Telegram в блоке «Контакт»
- Цифры в статистике (15+ лет, 50+ объектов)
- Города в блоке «Уральский регион»

## Запуск

Откройте `index.html` в браузере или опубликуйте через `publish-github.ps1`.
